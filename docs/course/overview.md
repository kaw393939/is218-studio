# Imagine it. Build a working version. Learn from it.

**Use AI to attempt something more imaginative than you thought you could make.** Then show how testing, design patterns and architecture helped you turn the idea into software you understand. Your creative project may use any language, framework or engine.

## Two projects, with Studios inside the work

| Work | What you will show |
| --- | --- |
| **[Individual creative application](/projects/individual)** | A bold idea, one finished user journey and an honest AI experiment. RPS, another simple game or a non-game idea can supply the core. |
| **[Group business workflow](/projects/group)** | One useful business task completed together, with each member's design, implementation and review work. |
| **[Studios](/projects/studios)** | Focused testing, pattern and architecture practice inside the chosen app. Link the same code/checks from the project review. |

[Start the idea-discovery workshop](/projects/creative-challenge). Keep a **Dream**, a **working promise** and an **experiment** in the same record. A clear promise controls the workload while leaving room for ambition.

## Follow one class at a time

<ProcessFlow />

**Introduce → next class: work and review → submit and carry forward.** Keep one spec/record per project. Compare two meaningful approaches, build a usable slice, then improve it through real peer feedback and tests. Use [your section card](/course/schedule) for dates.

Reviews 1–4 are checkpoints: Plan → first slice → integrated build → improve/handoff. Both middle reviews develop the Build phase. At each review, add the current engineering decision and actual result to the same record, rather than another report.

## Why this prepares you for professional work

An engineer has to turn an uncertain goal into a usable result, judge generated code, explain tradeoffs and work with other people. Your tests, architecture decisions and response to AI's successes or disappointments are evidence of that practice. [Connect it to FDE work](/career/fde).
